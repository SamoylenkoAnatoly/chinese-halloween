# Двор Тихой Луны 🏮

Хэллоуин-курс китайского языка для начинающих (Stepik, курс 303598 «Китайский с нуля (Хэллоуин)»).

Магистр Коко чихнул с неправильным тоном — и на старом кладбище проснулись добрые обитатели,
у которых стёрлась память. Зажги все 25 Фонариков Памяти китайскими знаками до рассвета!

## Персонажи

- **Магистр Коко** — отвечает за звуки и тоны («Голос Коко», «Тоны полуночи»)
- **Скелетик Костик** — гид и учитель каллиграфии («Мел и камень»)
- **Призрак Люми** — смотритель Фонариков Памяти («Сладость или гадость», финал)
- **Мышь Эхо** — жительница колокольни, помнит все звуки (повторяет тоны, ведёт «Осаду домика»)

## Программа (6 разделов, 25 фонарей)

1. Пробуждение — пролог-комикс + «Тоны полуночи»
2. Крыло Луны — 月 夕 日 明 木 林
3. Крыло Сердца — 目 口 心 白 人
4. Крыло Памяти — 名 自 想 息 众 朋
5. Слова-заклинания — 明月 明白 名人 人口 众人 人心 日月 月日
6. Праздник — большая викторина, финал и бонус-игра «Осада домика»

Каждый урок — 4 фазы: **Туман** (паспорт знака) → **Голос Коко** (звук + тон + сказка-мнемоника)
→ **Мел и камень** (письмо hanzi-writer, 3 раунда) → **Сладость или гадость** (5 вопросов, зажжение фонаря).

## Структура

```
index.html            — карта двора (SVG-сцена, прогресс в localStorage)
story/ tones/ finale/ bonus-siege/ — спец-страницы
lesson/<знак>/        — 25 сгенерированных уроков
shared/               — стиль, движок, персонажи (пиксель-SVG), lesson-data.js
audio/                — mp3 произношения (тоновые ma1–4 + знаки и слова)
build/                — генераторы: data.py (контент), build.py (сайт),
                        make_characters.py (пиксельные SVG), publish_stepik.py
```

## Локальный запуск

```bash
python build/build.py     # регенерация уроков
python -m http.server     # http://localhost:8000
```

Зависимости сайта: только hanzi-writer и шрифты с CDN. Аудио-движок и SFX — WebAudio.
